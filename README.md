# food-cart

Модуль кошика і промокодів мобільного застосунку доставки їжі «Смакота» (лабораторна робота 4, «Гнучкі технології розробки ПЗ»).

Реалізує user story **FOOD-18** «Застосування промокоду» з Jira-проєкту FOOD.

```bash
pip install -r requirements.txt
pytest -v
```

Тести автоматично запускаються в GitHub Actions на кожен push і pull request (`.github/workflows/ci.yml`).
